# Instruction Following Evaluation

## Task Type
Instruction adherence and response quality evaluation for LLM outputs.

## Prompt
"Summarize the following medical note in simple language suitable for a non-technical user."

## Model Response (Sample)
The patient has been experiencing high blood pressure and headaches. They are advised to continue medication and follow up with their doctor.

## Evaluation Criteria
- Instruction adherence
- Clarity
- Completeness
- Tone appropriateness

## Score
4 / 5

## Rationale
The response follows the instruction and uses simple language. However, it omits some contextual details from the original note.
